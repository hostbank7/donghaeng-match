# 동행매치

서울·경기·인천 후불제 상조 매칭 플랫폼의 시연용 웹사이트입니다.

사이트 주소: https://hostbank7.github.io/donghaeng-match/

고객이 원하는 장례 조건과 희망 금액으로 요청서를 올리면, 동행매치가 직접 검증한 후불제 상조회사가 항목별 견적으로 제안합니다. 협의는 사이트 채팅과 050 안심번호로만 하고, 결제는 장례를 마친 뒤에 합니다.

## 화면 구성

- **고객**: 긴급 간편 접수, 장례 요청서(권장 인력 구성 자동 계산, 검증 파트너 단가 기준 예상 금액, 장례식장 포함 총비용, 제휴 기관 소개 코드), 요청서 사전 저장, 회원가입·로그인, 내 문의 내역, 제안 비교표와 가족 공유, 채팅, 요청 수정·취소, 매칭 확정, 용품 사진 확인, 추가 비용 승인, 정산서 확인, 해피콜, 리뷰, 모바일 부고장
- **상조회사**: 출동 가능 상태, 내 실적, 요청 게시판, 항목별 견적 제안, 내 단가표, 파트너 검증 신청
- **운영자**: 긴급 관제, 파트너 검증, 해피콜 입력, 직거래 의심 건 처리, 제재 관리, 추가 비용·정산 이의, 표준 인력 기준, 업체 단가표, 제휴 기관

## 문서

- 업체, 요청, 점수, 단가, 전화번호, 회사 정보는 모두 예시입니다.
